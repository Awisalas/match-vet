# F13 V2 model contract

`ModelContractRepository` retains separate schema-2 model input and result contracts in protected ArtifactStore objects. It requires an exact F11 evidence-set digest and F07 cutoff ID. F11 replay verifies the corresponding F06 freeze, membership and controlling fixture revision before F13 builds a target. There is no database migration.

`retain_history(history)` records explicitly supplied upstream structured-history assertions and returns `HistoricalMatch` rows bound to those exact source bytes. This retention establishes the source snapshot identity; provider authenticity remains the upstream acquisition owner's responsibility. Build and replay resolve each row against its protected source snapshot, including teams, kickoff, metric states, values, input IDs and observation/publication times. A changed row cannot retain its old source digest. Untyped inputs and unsupported fields fail closed.

`build(evidence_digest, cutoff_id, history=retained_rows, calibration_cases=cases)` freezes the historical inputs valid for that match cutoff. Rows with missing observation time or source lineage, post-cutoff timestamps, or the target fixture ID remain recorded as exclusions. Duplicate fixture IDs are refused. Unknown metrics retain their states and cannot become observed model facts.

Each family result retains its fixture, exact input digest and predecessor lineage, model version, fit digest and protected artifact digest, consumed feature/input IDs and digests, raw prediction digest and distribution, calibration version/digest, calibrated output, availability state, and uncertainty. Input identity includes the explicit T11, T12, T13 and T14 model, algorithm, feature and configuration versions. The four families are full-time goals, first-half goals, second-half goals and corners.

The adapter passes verified F11 workload and weather into the existing T09 feature builder. An exact F12 weather attempt becomes a cutoff-checked weather research attempt. Other research gaps remain explicit. F10 catalog identity is retained; requirements without a V2 assessment remain UNKNOWN, with an explicit assessment basis. Quantitative historical support, research sufficiency and contextual observations remain distinct. Context alone cannot make a model available.

`CalibrationCase(prediction_contract_digest, fixture_id, family)` names a prior F13 prediction. Its observed counts come from the current protected history snapshot, using the existing half-goal derivation rules where applicable. The prior contract must replay, have the same model version, and name the exact outcome fixture, teams, kickoff and known competition. Outcomes must be available by the current cutoff. Unknown outcomes supply no calibration facts. The unchanged T14 fitter retains its chronological and leakage checks. Missing calibration remains unavailable, with no calibrated probability or interval.

`replay(result_digest, evidence_digest, cutoff_id)` verifies all protected sources, predecessor identities and model artifacts, then recomputes and compares exact canonical bytes. Unsupported schemas, extra input fields, wrong membership/evidence/cutoff references and corrupt artifacts fail closed. Identical sources, versions and input ordering produce identical bytes and digests. Replay never refreshes acquisition.

T11 through T14 V1 functions, serializers, canonical artifacts and digests remain unchanged. The V2 model, prediction and calibration envelopes have distinct media types and bind their embedded V1 payloads to the V2 input digest. Bookmaker odds have no accepted input field.
