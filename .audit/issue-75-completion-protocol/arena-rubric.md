# Design comparison rubric

Each criterion scores 0-2; reject any candidate scoring 0 on correctness or recovery.

1. Proves fresh durable selection commit returned before conservative repository T comparison.
2. No persisted state, generic API, retry, reopen, fork, or other proposal can mint receipt authority.
3. Missing receipt after ambiguous crash permanently refuses the indexed Matchweek; intact receipt permits exact replay.
4. Existing immutable bytes/readers/schema remain usable; namespace/API extension is explicit.
5. Trusted UTC/elapsed clocks and file/WAL durability assumptions are explicit and bounded honestly.
6. One deep owner hides all multi-stage timing and receipt orchestration from callers.

Available runner families substitute for unavailable default harness slugs:
gpt-6-astra and gpt-5.6-sol. Research uses gpt-6-sol. Production implementation is excluded.
