# Issue #84 integrated successor proof

Scope: [#84](https://github.com/Awisalas/match-vet/issues/84) and the original
acceptance contract in [#80](https://github.com/Awisalas/match-vet/issues/80).
ADR 0003 and the accepted causal Matchweek design were not changed. No production
module, database schema, live store, source activation, live fixture, live TSA/TUF
service, or full suite was used.

## Integrated execution

The integrated fixture uses all seven F06 scopes, with synthetic included fixtures
on Friday, Saturday and Monday. Serie A supplies the earliest kickoff. The exact
F06/F07/F11/F12/F13/F14/F15/F16 graph is admitted and durably written before a
fresh v2 selection. Every included F07 has `T = earliest included kickoff -
21600 seconds`.

The witness callback observes the committed selection and absent completion slot,
then checks the exact selected digest, F16 digest, logical Matchweek ID, request
imprint and nonce. It signs a deterministic timestamp with a locally generated
P-384 TSA certificate and runs the real profile verifier. The signed upper bound
is before T. The callback advances the deterministic delivery clock to after T
before returning the response; the completion receipt is then indexed. Reopening
the store replays the exact indexed receipt without another request.

The same reopened store replays the prior v1 selection, receipt, F16 manifest and
every retained canonical graph object byte-for-byte. CB01 then records one
unavailable witness, one successful enrollment, and the remaining unattempted
included fixture while preserving all denominator rows. Its independent TSA
check is asserted as `T < signed genTime < controlling kickoff`. Evaluation
reports causal selection-v2. F19 creates a pending settlement and an append-only
correction bound to the same selection, receipt, F16 result and F14 decision;
replay is byte-identical and the frozen prediction input and graph bytes remain
unchanged.

The synthetic event and retained public Sigstore/TUF wire checks are separate.
The integrated tests forbid socket connections. Synthetic keys and timestamps
are generated locally; CB01 uses its deterministic test backend. No real network
or live trust service is contacted.

## Assumptions, outcomes and remaining scope

The proof is local to one honest Store/catalog history and assumes trusted code and
kernel behavior plus SQLite WAL/FULL durability, VFS `fsync`, locking and process
ownership. The verifier establishes the signed interval and authenticated pinned
trust closure; it cannot detect hidden UTC smear or independently establish
operator accuracy/compliance. Retained TUF history does not prove current
revocation status. Offline compromise limits and those trust premises remain
explicit. Network, source and receipt outages reduce availability and can leave an
occupied slot permanently unqualified. Production profile activation continues
to raise `Authenticated causal profile activation is unavailable`; this proof does
not enable a live source, #70 fitting, or promotion.

No production defect was found, so no production fix or schema change was needed.
The only change to an existing helper is test-only: it accepts an optional
synthetic `matchweek_friday` and defaults to the prior historical date. No
production Python module changed.
